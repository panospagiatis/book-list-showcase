# Book List Showcase

A small React project that displays a list of books in a responsive card layout.

I built this project while following a React tutorial to practice working with components, TypeScript, Tailwind CSS, and responsive layouts.

## What I practiced

- Creating reusable React components
- Using TypeScript for book data
- Rendering a list of books from an array
- Styling the UI with Tailwind CSS
- Creating a responsive grid layout
- Adding accessible alt text to book cover images

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Running locally

```bash
npm install
npm run dev
```
